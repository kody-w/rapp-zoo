# Rolling Cores Commercial Model

## Promise

**Everything autocomplete on an organism.**

People meet and preview Rapters for free. When they value one, they purchase
that organism once and receive its signed Rolling Core Capsule as a local
artifact they own.

Local identity and history are never held hostage by payment status.

## Modes

### Direct

Direct mode is the free/private path:

- one local Rapter;
- any OpenAI-compatible provider;
- bring-your-own endpoint, model, and API key;
- credentials stored in the device's secure credential store;
- local Holo/1 validation, playback, history, SHAPEE, and Growl;
- provider usage billed directly to the user;
- no Rapterbox model proxy required.

### Wild

Wild mode is optional managed computation:

- Rapterbox Azure Function Brainstem;
- one OpenAI-compatible client contract regardless of upstream provider;
- server-side provider credentials;
- scoped user/device/organism access;
- quotas, rate limits, revocation, routing, and usage accounting;
- remote access and cross-device continuity;
- managed autocomplete services.

The Azure Function is an additional Brainstem and security boundary, not a
requirement for local operation.

Storefronts and RevenueCat supply localized prices. Prices are not hardcoded in
the app or protocol.

## What payment unlocks

An organism purchase provides:

- a signed, content-addressed Rolling Core Capsule;
- local ownership and offline playback;
- import through Files, Share Sheet, AirDrop, or backup;
- export and transfer of the owned artifact;
- restoration/redownload through a receipt-backed account ledger.

Separate compute packs cover Rapterbox-operated resources:

- Wild Brainstem inference;
- hosted provider routing;
- longer managed Growl completions;
- deeper hosted recursive-history windows;
- remote encrypted synchronization;
- exports generated by hosted workers;
- shared Rappter rooms such as the fantasy draft.

Payment does not control:

- ownership of local frames;
- ability to inspect or export locally owned data;
- RAPP/1 verification;
- playback of already-owned local Holo records;
- use of a user's own provider key in Direct mode.

## Store implementation

The Expo app uses RevenueCat for App Store and Google Play one-time products.

- Expo Go displays a clearly labeled preview paywall only.
- Native purchase testing requires an EAS development build.
- Rapter and compute packs are consumable store products.
- Every store transaction ID is redeemed idempotently into the Rapterbox
  ownership/credit ledger.
- Store API keys are public SDK identifiers, supplied through build
  configuration.
- Azure, OpenAI, Anthropic, and Function master keys are never included in the
  app bundle.
- Signing back into Rapterbox restores owned organisms and unspent credits from
  the server ledger; the client never relies on a consumable receipt as its only
  ownership record.
- A customer can see which organisms consumed each purchased Rapter credit.

## Wild authorization

A released client does not receive the Azure Function master key.

1. The user authenticates.
2. The ownership service confirms any requested hosted organism is owned and
   that sufficient optional compute balance remains.
3. The service issues a short-lived token scoped to user, device, organism, and
   allowed operation.
4. The Azure Function verifies that token, quota, and revocation state.
5. The Function routes the OpenAI-compatible request to the configured provider.

For private development only, a Function key may be provisioned into macOS
Keychain or mobile secure storage. It is never committed, logged, embedded, or
sent through chat.

## Cost controls

- Reuse an existing compatible model deployment before creating another.
- Default Wild traffic to the least expensive model meeting the task's quality
  threshold.
- Reserve larger models for explicit high-quality generation.
- Debit explicit managed-compute credits and enforce abuse ceilings.
- Cache immutable completed traits by content address.
- Do not bill repeated reads or playback as new inference.
- Surface usage before the quota is exhausted.
