## Description

Holo Zoo is a local-first habitat, player, library, Field, and Observatory for
signed Rolling Core organisms called Rapters.

Explore an offline Holo Field built from public organism IDs. Choose
Overwatch, Scout, Forge, or Sentinel as a local House perspective. The Field
requests no GPS, contacts no map provider, creates no physical destination,
and gives every House the same encounter roster.

Meet Rapters in commerce-free Companion mode. Play completed Holo and Growl
expressions, inspect immutable history and source evidence, import signed
`.rollingcore` capsules, and export local capsules through the system share
sheet.

Configure an OpenAI-compatible Direct provider only if you choose. Provider
keys use native secure storage, key testing calls only `/models`, and bounded
updates start only after explicit action. Updates stop when iOS suspends the
app.

The Work walkthrough demonstrates request, status, proof, and delivery screens.
It is deterministic and local only. No AI job is created or run, no funds are
reserved, and no work or proof event is published.

The current build has no account, purchase, production job, tip, sponsorship,
rental, resale, managed-compute sale, Coin economics, public sharing, external
interoperability, or automatic RapterBox telemetry.

The TestFlight is for adult internal testers only.

## App Review notes

- The app opens with bundled local content and requires no account.
- Audience is adult internal testers only.
- Holo Field requests no location permission and uses no map provider.
- Houses are local-only and affect no price, rank, power, access, encounter,
  Growth, companionship, or economic outcome.
- Companion mode contains no commercial action.
- Work mode is labeled **UI WALKTHROUGH ONLY**.
- Walkthrough controls advance explanatory local state only.
- The walkthrough creates no official job, work, proof, artifact, delivery,
  payment, review, public proof, Coin, or service claim.
- Real commerce and RevenueCat initialization are blocked by the tracked
  runtime release policy even if an environment key is present.
- Production RapterWorks, public sharing, external interoperability, and
  irreversible protocol writes are disabled.
- OTA updates are disabled.
- Direct provider keys use Expo SecureStore. A fresh-install sandbox marker
  causes any residual Keychain key from an earlier uninstall to be deleted
  before settings load.
- The app contains no automatic telemetry. Its error boundary uploads nothing.
- Apple may process TestFlight feedback and diagnostics under Apple's policies.
- Imports are capped at 16 MiB and temporary picker/export cache files are
  removed.
- Public hosts require HTTPS. HTTP is restricted to literal loopback/private
  network addresses, and cross-origin redirects are rejected.
- No hardware MIDI device is opened. Audio begins only after an explicit Play
  action.
- Awake, Sleeping, Quarantined, and Unborn come from verified host evidence;
  Waking is transient UI, not a server state.
- The app makes no biological sentience or scientific consciousness claim.
- The dormant Rapter Coin Trail has no visible balance, wallet, market,
  transfer, redemption, cash value, or yield.
